# NOVA - Personal Voice Assistant 🤖

NOVA is a Python-based personal voice assistant that can listen to voice commands and perform different tasks using Python, APIs, and automation.

## 🚀 Features

- 🎙️ Voice command recognition
- 🔊 Text-to-speech responses
- 🌐 Open YouTube, Google and Instagram
- 🕐 Tell current time
- 📅 Tell current date
- 🎵 Search music on YouTube
- 🧮 Open Calculator
- 📝 Open Notepad
- 🔍 Google search
- 🌤️ Live weather information
- 📰 Latest news headlines

## 🛠️ Technologies Used

- Python
- SpeechRecognition
- PyAudio
- pyttsx3
- Requests
- python-dotenv
- wttr.in API
- NewsData.io API
